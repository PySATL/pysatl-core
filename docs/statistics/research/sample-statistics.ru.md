# Выборочные статистики: исследование S0–S13

[English version](sample-statistics.en.md) · [RFC](../rfc/rfc.ru.md).

Карточки описывают математический смысл статистик, значимые параметры,
условия применимости и требования, которые влияют на архитектуру.
Общие правила приведены в [выводах](#выводы); детали API задаёт RFC.
Выбранные реализации предварительны.

Обозначения: `n` — число наблюдений, `x_i` — наблюдение, `r` — порядок момента.
`x_(i)` — i-е значение после [сортировки S0](#s0-сортировка-массива); в формулах ранги
начинаются с 1. `C(a,b)` — число способов выбрать `b` элементов из `a`.

## S0. Сортировка массива

Вспомогательная функция для расчёта статистик: возвращает массив наблюдений,
отсортированный по возрастанию. Повторы сохраняются, исходный массив не меняется.

**Пример:** `[8, 2, 1, 2]` → `[1, 2, 2, 8]`.

**Особенности реализации:** сортировка выделена в отдельную вспомогательную функцию,
чтобы при включённом кэшировании сохранять отсортированный массив в сессии
и использовать его в нескольких расчётах на одной выборке без повторной сортировки.

**Выбранная реализация:** `numpy.sort`.

## S01. Выборочное среднее

Среднее описывает положение данных: это сумма всех наблюдений, делённая
на их количество. Большие по модулю значения могут заметно сдвигать ответ.

**Формула:** `mean = sum(x_i) / n`.

**Пример:** `[1, 2, 4, 8]` → `15/4 = 3.75`. Если заменить `8` на `80`,
среднее вырастет до `21.75`.

**Параметры и соглашения:** —

**Численная особенность:** сумма может переполниться до деления на `n`.
Масштабирование помогает избежать этого: можно разделить значения на подходящее
положительное число `x`, найти среднее и умножить его на `x`.
Исходная выборка не меняется; расход памяти от этого не уменьшается.

**Выбранная реализация:** стандартное среднее NumPy.

**Референс сравнения:** [NumPy mean](https://numpy.org/doc/stable/reference/generated/numpy.mean.html).

## S02. Выборочная дисперсия

Дисперсия измеряет разброс относительно среднего: усредняются квадраты
отклонений. Она выражается в квадрате исходных единиц; её квадратный корень —
стандартное отклонение — имеет исходные единицы.

**Формула:** `variance = sum((x_i - mean)^2) / (n - ddof)`.

**Параметры и соглашения:** `ddof` — число, вычитаемое из количества наблюдений
в делителе. При `ddof=0` делим на `n`, при `ddof=1` — на `n−1`.
Первый вариант описывает разброс самой выборки; второй даёт несмещённую оценку
дисперсии распределения для независимых одинаково распределённых наблюдений
с конечной дисперсией. В первой версии поддерживаются целые `ddof >= 0`.

**Пример:** для `[1, 2, 3]` среднее равно `2`, сумма квадратов отклонений — `2`.
При `ddof=0` ответ `2/3`, при `ddof=1` — `1`.

**Условия:** `n > ddof`, иначе делитель недопустим. Константная выборка
при допустимом делителе даёт нулевую дисперсию.

**Особенности реализации:** `ddof` — параметр конкретной статистики: он меняет ответ
и минимально допустимый размер выборки. Для вычисления требуется среднее [S01](#s01-выборочное-среднее).

**Выбранная реализация:** сначала среднее, затем квадраты отклонений и деление
на `n−ddof`. Формула `mean(x_i^2) - mean(x_i)^2` не используется: она может
терять точность при больших значениях с малым разбросом.

**Референс сравнения:** [NumPy var](https://numpy.org/doc/stable/reference/generated/numpy.var.html).

## S03. Начальные моменты

Начальный момент порядка `r` — среднее значений в степени `r`.
Первый момент равен среднему, второй — среднему квадрату, а не дисперсии.
Порядок показывает, в какую степень возводятся значения; высокие порядки
сильнее выделяют большие по модулю наблюдения.

**Формула:** `m_r = mean(x_i^r)`.

**Пример:** для `[1, 2, 3]` получаем `m_1=2`, `m_2=14/3`, `m_3=12`.

**Параметры и соглашения:** один или несколько целых порядков `r >= 0`.
Нулевой момент принимается равным `1`, включая выборки с нулями.
Отрицательные и дробные порядки в первую версию не входят.

**Особенности реализации:** поддерживается запрос нескольких порядков с сохранением
их последовательности и повторов. Эти моменты нужны также методу моментов
и обобщённому методу моментов в модуле оценивания.

**Выбранная реализация:** отдельно для каждого порядка — степени наблюдений
и их среднее средствами NumPy. Высокие степени могут переполняться.

**Референс сравнения:** [SciPy moment с center=0](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.moment.html).

## S04. Центральные моменты

Центральный момент порядка `r` — среднее степеней отклонений от выборочного
среднего. При добавлении одной константы ко всем наблюдениям он не меняется.
Второй центральный момент равен дисперсии с делителем `n`.
Третий и четвёртый используются для описания асимметрии и формы распределения.

**Формула:** `c_r = mean((x_i - mean(x))^r)`.

**Пример:** для `[1, 2, 3]` получаем `c_2=2/3`, `c_3=0`.
У `[101, 102, 103]` эти значения такие же.

**Параметры и соглашения:** один или несколько целых порядков `r >= 0`;
центр — строго выборочное среднее. Математически `c_0=1`, `c_1=0`.
Для `c_2` поправка `ddof` не применяется.

**Особенности реализации:** используется среднее [S01](#s01-выборочное-среднее).

**Выбранная реализация:** вычислить среднее и отклонения, затем усреднить
их степени. Восстановление через начальные моменты может терять точность;
высокие степени могут переполняться.

**Референс сравнения:** [SciPy moment](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.moment.html).

## S05. Выборочные квантили

Квантиль уровня `p` описывает границу нижней доли `p` данных.
На конечной выборке одного уровня недостаточно: нужно определить,
выбирается ли наблюдение или значение между соседними наблюдениями.

**Формула для линейной интерполяции:** позиция в массиве с индексацией от 0 —
`h=(n−1)p`. При `j=floor(h)` и `d=h−j` результат равен
`(1−d) × sorted[j] + d × sorted[j+1]`; если `d=0`, берётся `sorted[j]`.
`floor` означает округление вниз, `sorted` — отсортированную выборку.

**Пример:** для `[1, 2, 4, 8]` при `p=0.5` линейная интерполяция даёт `3`,
а обратная эмпирическая функция распределения (`inverted_cdf`) — `2`.
При `p=0.75` линейная интерполяция даёт `5`.

**Параметры и соглашения:** один или несколько уровней `0 <= p <= 1` и метод
определения квантиля. Для описанных методов уровни `0` и `1` дают минимум
и максимум. Уровни могут повторяться и идти в произвольном порядке.

**Особенности реализации:** метод — часть определения статистики, поэтому менять
его при численной ошибке нельзя. Нужно сохранять соответствие между уровнями
запроса и значениями результата.

**Выбранная реализация:** [S0](#s0-сортировка-массива) и формула выбранного соглашения.

**Референс сравнения:** [NumPy quantile и соглашения Hyndman–Fan](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html).

## S06. Порядковые статистики

Порядковая статистика — наблюдение на заданном месте после сортировки.
Первая — минимум, последняя — максимум. В отличие от интерполированного
квантиля, результат всегда является исходным наблюдением.

**Пример:** `[8, 1, 4, 2]` после сортировки даёт `[1, 2, 4, 8]`.
Индекс API `2` выбирает `4`. Для `[2, 2, 5]` индексы `0` и `1` оба дают `2`.

**Параметры и соглашения:** один или несколько индексов. В публичном API
предварительно принята индексация с 0: `0 <= index < n`.
Математические ранги в формулах начинаются с 1.

**Особенности реализации:** повторы данных занимают отдельные места; удалять их
перед вычислением нельзя. Порядок и повторы запрошенных индексов сохраняются.

**Выбранная реализация:** выбор элементов результата [S0](#s0-сортировка-массива).

**Референс сравнения:** [NumPy partition](https://numpy.org/doc/stable/reference/generated/numpy.partition.html) — для сравнения выбранных значений.

## S07. Медиана

Медиана — середина упорядоченных данных: центральное наблюдение при нечётном
`n`, среднее двух центральных — при чётном. Величина далёких от центра
наблюдений влияет на неё меньше, чем на среднее.

**Пример:** для `[1, 2, 3, 4, 100]` медиана равна `3`, среднее — `22`.
Для `[1, 2, 4, 8]` медиана равна `(2+4)/2 = 3`.

**Параметры и соглашения:** —

**Важное различие:** правило для чётного `n` зафиксировано в определении выше.
Оно отличается от квантиля `p=0.5` по обратной эмпирической функции
распределения, который для `[1, 2, 4, 8]` равен `2`.

**Выбранная реализация:** центральный элемент или среднее двух центральных
из результата [S0](#s0-сортировка-массива).

**Референс сравнения:** [NumPy median](https://numpy.org/doc/stable/reference/generated/numpy.median.html).

## S08. Усечённое среднее

Усечённое среднее — среднее после удаления заданной доли самых малых
и самых больших наблюдений. Левое и правое усечения могут различаться.

**Формула:** при долях `a` слева и `b` справа удаляются `l=floor(n×a)`
и `u=floor(n×b)` наблюдений; затем считается среднее оставшихся.
`floor` — округление вниз.

**Пример:** у `[1, 2, 3, 4, 100]` при усечении по 20% с каждой стороны
остаются `[2, 3, 4]`, среднее равно `3`. Для четырёх наблюдений те же доли
ничего не удалят: `floor(4×0.2)=0`.

**Параметры и соглашения:** отдельные доли `a,b >= 0`; количество удаляемых
наблюдений округляется вниз. Должно остаться хотя бы одно: `l+u < n`.

**Особенности реализации:** —

**Выбранная реализация:** [S0](#s0-сортировка-массива), выделение оставшегося диапазона и среднее.

**Референс сравнения:** [SciPy trim_mean](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.trim_mean.html) — для симметричного усечения.

## S09. Вероятностно-взвешенные моменты (PWM)

Для непрерывного распределения PWM порядка `r` определяется как
`E[X × F(X)^r]`, где `F(X)` — вероятность получить значение не больше `X`.
В степень возводится вероятность, а не наблюдение. В выбранной выборочной
оценке верхние ранги при `r>0` получают больший вес. При `r=0` получается
обычное среднее. PWM используются для вычисления L-моментов.

**Выборочная формула:**
`b_r = (1/n) sum_{i=r+1}^n [C(i−1,r)/C(n−1,r)] × x_(i)`.
Её смысл — средний максимум всех подвыборок размера `r+1`, делённый на `r+1`.
Подвыборки выбираются без возвращения.

**Пример:** для `[1, 2, 4, 8]` и `r=1` множители равны `[0, 1/3, 2/3, 1]`.
Поэтому `b_1=(0×1 + (1/3)×2 + (2/3)×4 + 1×8)/4 = 17/6`.
Множители не нормируют до суммы один.

**Параметры и соглашения:** целые порядки `r >= 0`, для каждого требуется
`n >= r+1`. Выбрана комбинаторная оценка по формуле выше.

**Важное различие:** для распределения с точечными вероятностями эта формула
оценивает `E[max(X_1,…,X_(r+1))]/(r+1)`, что может отличаться от буквального
`E[X × F(X)^r]`. Например, если `X` всегда равен `1`, значения равны
`1/(r+1)` и `1` соответственно. Подстановка эмпирической функции
распределения вместо `F` также задаёт другую оценку.

**Особенности реализации:** соглашение PWM нужно фиксировать явно и согласовать
с L-моментами [S11](#s11-l-моменты). Разные определения нельзя выдавать за один метод.

**Выбранная реализация:** [S0](#s0-сортировка-массива), затем рекуррентное
вычисление множителей от старших рангов к младшим, без построения больших
биномиальных коэффициентов.

**Референс сравнения:** [Greenwood et al., 1979](https://doi.org/10.1029/WR015i005p01049),
[NIST L-moments](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/lmoment.htm).

## S10. Общие L-статистики

L-статистика — линейная комбинация упорядоченных наблюдений.
Вес относится к месту в отсортированном ряду, а не к конкретному наблюдению
до сортировки.

**Формула:** `L = sum(w_i × x_(i))`.

**Пример:** для `[1, 2, 4, 8]` веса `[1/2, 0, 0, 1/2]` дают середину между
минимумом и максимумом — `4.5`. Веса `[-1/2, 0, 0, 1/2]` дают половину
размаха — `3.5`.

**Параметры и соглашения:** веса или правило их построения для размера `n`.
Веса конечны, их количество равно `n`. Они могут быть отрицательными
и не обязаны суммироваться в `1`. Можно запросить несколько наборов весов.

**Особенности реализации:** ранговые веса — часть определения статистики;
вероятностная нормировка для них не нужна. Явные веса привязаны к размеру
выборки, а правило построения должно однозначно определять их для данного `n`.

**Выбранная реализация:** скалярное произведение весов и результата
[S0](#s0-сортировка-массива) средствами NumPy, по одному набору весов.

**Референс сравнения:** [NumPy dot](https://numpy.org/doc/stable/reference/generated/numpy.dot.html):
`np.dot(weights, np.sort(sample))` с теми же ранговыми весами.

## S11. L-моменты

L-моменты — L-статистики со специальными весами. Первый равен среднему,
второй описывает разброс и равен половине средней абсолютной разности
по всем парам наблюдений с различными индексами. Третий и четвёртый
используются для описания асимметрии и формы после нормировки.
Наблюдения не возводятся в высокие степени, но крайние значения всё ещё
могут влиять на ответ.

**Формула через PWM из [S09](#s09-вероятностно-взвешенные-моменты-pwm):**
`l_r = sum_{j=0}^{r−1} (−1)^(r−1−j) × C(r−1,j) × C(r−1+j,j) × b_j`.
В частности, `l_1=b_0`, `l_2=2b_1−b_0`.

**Пример:** для `[1, 2, 4, 8]` имеем `l_1=15/4`.
Сумма шести попарных абсолютных разностей равна `23`, поэтому
`l_2=(23/6)/2 = 23/12`. В отличие от дисперсии, единицы `l_2` совпадают
с единицами исходных данных.

**Параметры и соглашения:** целые порядки `r >= 1`, требуется `n >= r`.
Выбраны несмещённые оценки через комбинаторные PWM.
У константной выборки `l_1` равен константе, остальные L-моменты — нули.
Существование всех соответствующих моментов распределения обеспечивается
конечным `E|X|` — математическим ожиданием абсолютного значения.

**Особенности реализации:** используются PWM из [S09](#s09-вероятностно-взвешенные-моменты-pwm) с тем же соглашением;
сортировка [S0](#s0-сортировка-массива) выполняется при расчёте PWM.
Сами L-моменты и их безразмерные отношения [S12](#s12-отношения-l-моментов) — разные результаты.

**Выбранная реализация:** преобразование PWM в L-моменты по формуле выше.

**Референс сравнения:** [SciPy stats.lmoment](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.lmoment.html)
(SciPy >= 1.15): `scipy.stats.lmoment(sample, order=orders, standardize=False)`.
Сравниваются сами L-моменты; при `standardize=True` порядки от 3 возвращаются
как отношения к второму L-моменту.

## S12. Отношения L-моментов

Отношения L-моментов — безразмерные характеристики относительного разброса
и формы. Нужно различать:

- `l_2/l_1` — L-коэффициент вариации: разброс относительно среднего уровня.
- `l_3/l_2` — L-асимметрия.
- `l_4/l_2` — L-характеристика формы хвостов; это не обычный эксцесс.

Отношения формы `l_r/l_2` при `r>=3` не меняются при добавлении константы
и умножении данных на положительное число. `l_2/l_1` зависит от начала отсчёта;
при отрицательном `l_1` обычная положительная интерпретация относительного
разброса не сохраняется.

**Пример:** для `[1, 2, 4, 8]` значения `l_1=15/4`, `l_2=23/12`, `l_3=3/4`
дают `l_2/l_1=23/45`, `l_3/l_2=9/23`.
У `[3, 3, 3]` знаменатель `l_2=0`, поэтому L-асимметрия не определена.

**Параметры и соглашения:** выбираются `l_2/l_1` и/или порядки `r>=3`
для отношений `l_r/l_2`. Требования к размеру выборки — как у участвующих
L-моментов [S11](#s11-l-моменты); знаменатель должен быть ненулевым.

**Особенности реализации:** используются L-моменты [S11](#s11-l-моменты). Допустимость зависит
от конкретного отношения: нулевой `l_1` запрещает `l_2/l_1`, но не обязательно
`l_3/l_2`. При ошибке одной компоненты отклоняется весь векторный запрос
с указанием её позиции; отдельно запрошенные допустимые статистики доступны.

**Выбранная реализация:** деление нужных L-моментов. Нулевой знаменатель —
ошибка; близкий к нулю может усиливать погрешность. Универсальный абсолютный
порог для ненулевого знаменателя не вводится: он зависел бы от единиц данных.

**Референс сравнения:** [Lmo l_ratio](https://jorenham.github.io/Lmo/api/L-moments/):
`lmo.l_ratio(sample, 2, 1, trim=0)` для `l_2/l_1`,
`lmo.l_ratio(sample, r, 2, trim=0)` для `l_r/l_2`.

## S13. Усечённые L-моменты (TL)

TL-моменты уменьшают влияние крайних рангов в определении L-моментов.
Левое усечение `s` и правое `t` задаются отдельно. Это не вычисление
обычных L-моментов после удаления крайних наблюдений из исходной выборки.

**Математический смысл:** для порядка `r` рассматриваются все подвыборки
размера `M=r+s+t`, выбираемые без возвращения. Обозначим через `A_(a,M)`
среднее a-х порядковых статистик этих подвыборок. Тогда
`l_r^(s,t) = (1/r) sum_{j=0}^{r−1} (−1)^j × C(r−1,j) × A_(r+s−j,M)`.
Без перебора подвыборок это среднее выражается как
`A_(a,M) = sum_{i=1}^n C(i−1,a−1) × C(n−i,M−a) × x_(i) / C(n,M)`.
Биномиальные коэффициенты вне допустимых границ принимаются равными нулю.

**Пример:** первый TL-момент с `s=t=1` — среднее медиан всех троек.
Для `[0, 1, 2, 10, 100]` медианы десяти троек равны `1` три раза,
`2` четыре раза и `10` три раза. Ответ `(3×1+4×2+3×10)/10 = 4.1`.
Если просто убрать `0` и `100`, среднее оставшихся равно `13/3 ≈ 4.333` —
это другая статистика.

**Параметры и соглашения:** целые порядки `r >= 1` и независимые
неотрицательные целые усечения `s,t`. Требуется `n >= r+s+t`.
Выбрана несмещённая оценка по формуле выше. При `s=t=0` получаются обычные
L-моменты; дробное усечение в первую версию не входит.

**Особенности реализации:** порядок и обе стороны усечения совместно определяют
минимальный размер выборки. Усечение меняет веса рангов, поэтому заменять
TL-момент L-моментом обрезанной выборки нельзя. Нулевые веса крайних рангов
сами по себе не уменьшают `n_used`.

**Особенность интерпретации:** некоторые TL-моменты распределения существуют,
даже если обычное среднее не существует. Проверяется существование ожиданий
нужных внутренних порядковых статистик, а не общее условие конечности `E|X|`.

**Выбранная реализация:** [S0](#s0-сортировка-массива), затем прямая формула
через биномиальные коэффициенты (`math.comb`), по одному порядку.

**Референс сравнения:** [Elamir–Seheult, 2003](https://durham-repository.worktribe.com/output/1560955),
[Hosking, 2007](https://doi.org/10.1016/j.jspi.2006.12.002).

## Выводы

- **Общий вход:** одномерная непустая выборка конечных вещественных чисел.
  `Sample.prepare` создаёт защищённый снимок `float64`, сохраняя порядок
  и повторы. Ограничения отдельных статистик, например `n > ddof`,
  проверяются самой статистикой.
- **Форма результата:** публичный результат — `StatisticResult`; число
  или вектор находятся в его поле `value`. Вектор сохраняет порядок и повторы
  запроса. Пустой запрос отклоняется. Если компоненту
  вычислить нельзя, весь запрос завершается ошибкой с её позицией.
- **Значимые параметры:** порядки, уровни, индексы, поправка делителя, усечения,
  веса и математические соглашения различают запросы и входят в ключ кэша.
  Они должны оставаться неизменными на протяжении жизни объекта статистики.
- **Общая подготовка рангов:** квантили, порядковые статистики, медиана
  и L-/TL-методы используют [S0](#s0-сортировка-массива). Её результат можно разделять
  между расчётами через механизм зависимостей RFC; исходный снимок не меняется.
- **Границы первой версии:** веса наблюдений и потоковая обработка
  не поддерживаются. Ранговые веса [S10](#s10-общие-l-статистики) и усечения [S08](#s08-усечённое-среднее)/[S13](#s13-усечённые-l-моменты-tl) относятся
  к определению статистик и не являются весами входного Sample.
- **Выборка и распределение:** эти статистики не требуют вероятностного
  семейства или подбора его параметров. Конечное выборочное значение
  не доказывает существования соответствующего момента распределения.
  Независимость и одинаковое распределение наблюдений автоматически
  не проверяются.
- **Численные ошибки:** конечные входные числа не гарантируют вычислимого
  результата при ограниченной точности. Общие правила ошибок заданы RFC;
  нельзя молча удалять наблюдения, подменять математическое соглашение
  или выдавать нечисловой либо бесконечный ответ как успешный результат.
